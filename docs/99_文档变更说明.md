# 文档变更说明

> 项目：Personal AI OS  
> 定位：开源、Local First 的个人认知操作系统  
> 当前主模型：DeepSeek（通过 Model Gateway 解耦）  
> 核心原则：Your Data. Your Memory. Your AI.  
> 文档状态：研发基线，可随代码迭代同步更新


## 本次相对早期 Word 文档的主要变化

1. 从“概念/宣传性描述”改成研发约束。
2. DeepSeek 定位为默认 Provider，但通过 Model Gateway 解耦。
3. V0.1 统一采用 PostgreSQL + pgvector，暂缓 Neo4j/Qdrant/Kubernetes。
4. 明确 Memory Candidate / Confirmed 生命周期。
5. 明确 AI 推断与事实分离。
6. API、数据库、删除级联、引用、异常处理增加工程约束。
7. 开源战略改为“不融资、Local First、数据自主”。
8. 代码架构由“多个独立 engine 服务”收敛为模块化单体，避免早期过度工程化。
9. 测试增加 RAG Groundedness、Citation、Memory Precision。
10. 商业化文档改为非融资开源可持续方案。
