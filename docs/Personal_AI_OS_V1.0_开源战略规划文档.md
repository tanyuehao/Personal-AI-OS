# Personal AI OS V1.0 开源战略规划

> 项目：Personal AI OS  
> 定位：开源、Local First 的个人认知操作系统  
> 当前主模型：DeepSeek（通过 Model Gateway 解耦）  
> 核心原则：Your Data. Your Memory. Your AI.  
> 文档状态：研发基线，可随代码迭代同步更新


## 1. 核心定位

Personal AI OS 是开源个人认知基础设施，不融资、不以 SaaS 锁定用户数据为目标。

## 2. 原则

- Local First
- Data Ownership
- Model Freedom
- Explainable Memory
- Replaceable Providers
- Community Maintained

## 3. 技术上的开源特色

项目真正的差异化应集中在：
- Memory Schema；
- Memory lifecycle；
- Belief evolution；
- Decision recall；
- Cognitive context composition。

RAG、聊天 UI、模型 SDK 都是基础设施，不应被当成核心壁垒。

## 4. 可持续性

非融资不等于不可持续。可采用：
- 社区赞助；
- 文档/社区共建；
- 企业自行部署；
- 第三方服务商生态。

核心仓库保持开放，不以功能阉割逼迫付费。
