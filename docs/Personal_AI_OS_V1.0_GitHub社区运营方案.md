# Personal AI OS GitHub 社区运营方案

> 项目：Personal AI OS  
> 定位：开源、Local First 的个人认知操作系统  
> 当前主模型：DeepSeek（通过 Model Gateway 解耦）  
> 核心原则：Your Data. Your Memory. Your AI.  
> 文档状态：研发基线，可随代码迭代同步更新


## 1. 运营目标

首要指标不是 Star，而是：
- 可复现安装；
- 有效 Issue；
- 外部 PR；
- Release 使用反馈；
- Memory/RAG 质量数据。

## 2. 社区节奏

- 每个 Release 发布 CHANGELOG；
- 每月维护一次 Roadmap；
- Discussions 收集真实使用场景；
- Good First Issue 保持 5~10 个。

## 3. Issue Label

- bug
- enhancement
- good first issue
- help wanted
- ai-quality
- memory
- retrieval
- docs
- deployment

## 4. 透明原则

公开：
- 已知限制；
- 失败案例；
- 模型依赖；
- 数据处理方式；
- Roadmap 取舍。
