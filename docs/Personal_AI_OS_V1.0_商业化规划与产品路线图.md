# Personal AI OS 非融资开源可持续规划与产品路线图

> 项目：Personal AI OS  
> 定位：开源、Local First 的个人认知操作系统  
> 当前主模型：DeepSeek（通过 Model Gateway 解耦）  
> 核心原则：Your Data. Your Memory. Your AI.  
> 文档状态：研发基线，可随代码迭代同步更新


> 本文替代早期“商业化/融资”假设。项目当前明确：开源、不融资。

## 1. 成功标准

项目成功不以融资估值衡量，而以：
- 是否有真实用户长期使用；
- 是否能保护用户数据主权；
- Memory 是否可靠；
- 是否有外部贡献者；
- 是否形成可持续维护机制。

## 2. 可持续方式

可以接受但不影响核心开源：
- GitHub Sponsors / 捐赠；
- 社区赞助；
- 第三方托管/部署服务；
- 企业自行付费找服务商定制；
- 周边生态。

## 3. 路线优先级

技术稳定 > 社区增长 > 功能数量。

不要为了吸引 Star 快速加入大量 Agent，而牺牲 Memory 与数据可靠性。
