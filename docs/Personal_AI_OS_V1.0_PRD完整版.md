# Personal AI OS V1.0 产品需求文档（PRD）

> 项目：Personal AI OS  
> 定位：开源、Local First 的个人认知操作系统  
> 当前主模型：DeepSeek（通过 Model Gateway 解耦）  
> 核心原则：Your Data. Your Memory. Your AI.  
> 文档状态：研发基线，可随代码迭代同步更新


## 1. 产品目标

Personal AI OS 的目标不是再做一个聊天机器人，而是建立一个可以长期积累个人数据、记忆和认知线索的 AI 工作空间。

V0.1 的验证问题只有三个：

1. 用户能否把自己的资料稳定地导入系统？
2. AI 能否基于用户资料可靠回答，并明确给出来源？
3. 系统能否从交互中沉淀少量、可解释、可编辑的长期记忆？

## 2. 核心用户场景

### 2.1 资料问答

用户上传项目文档、笔记、报告后提问：

> 我过去对这个行业的判断发生过哪些变化？

系统必须：
- 检索相关资料；
- 按时间组织；
- 区分“资料事实”与“AI推断”；
- 返回引用来源。

### 2.2 个人记忆

用户表达：

> 我做项目更看重长期现金流，而不是短期增长。

系统可生成候选 `Preference Memory`，显示来源、置信度，并允许用户确认、修改或删除。

### 2.3 决策复盘

用户记录一次重要决策：

- 背景
- 选项
- 选择
- 理由
- 风险
- 预期结果
- 实际结果
- 复盘

后续相似问题可召回该决策，但不得把历史选择当成当前必然答案。

## 3. 功能范围

### P0

| 编号 | 功能 | 验收重点 |
|---|---|---|
| P0-01 | 用户空间 | 数据按 user_id 隔离 |
| P0-02 | 文件上传 | PDF/DOCX/MD/TXT 可处理 |
| P0-03 | 文档解析 | 生成可追溯 Chunk |
| P0-04 | 语义检索 | Top-K 结果包含来源 |

| P0-06 | 引用展示 | 回答可定位文档/片段 |
| P0-07 | 基础 Memory | 可增删改查、可追溯 |

## 5. 非功能需求

### 隐私
- ✅ 默认本地保存；
- ✅ API Key 使用 Fernet 加密存储；
- ✅ 删除文档时同步删除其 Chunk/向量；
- ✅ 用户可导出自己的数据（JSON 格式）。

### 可解释性
- RAG 回答必须展示引用；
- Memory 必须展示来源；
- 认知推断必须标记为“推断”，不能伪装成事实。

### 性能
V0.1 以单用户/个人部署为目标：
- 一般页面 API P95 < 1s（不含 LLM）；
- 检索 P95 < 1.5s；
- 文档处理异步执行；
- LLM 超时必须可恢复。

## 6. V0.1 完成定义

一个新用户可以从空环境开始：

`安装 -> 配置 DeepSeek Key -> 上传资料 -> 等待索引 -> 提问 -> 查看引用 -> 确认记忆`

完整闭环无人工数据库操作，即视为 MVP 达标。
